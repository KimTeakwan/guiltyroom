개인정보 처리방침

시행일: 2026년 11월 · 이 사이트는 재미로 만든 개인 운영 사이트입니다.

1. 수집하는 정보

  • 이름, 이메일, 전화번호는 받지 않습니다. 로그인도 없습니다.
  • 처음 접속하면 이 기기에서만 쓰는 무작위 익명 계정 번호가 자동으로 만들어집니다.
  • 사용자가 직접 올린 고해 글, 댓글, 투표("쓰레기다"·"봐준다"), 신고, 신부님께 보낸 문의와 올린 시각.
  • 글을 올릴 때 화면에 보이는 무작위 별명(예: "○○ 동물 #42").
  • 이 기기의 브라우저에 저장되는 설정(효과음·BGM 켜기/끄기, 칭호 기록, 고해 기록 등). 서버로 보내지 않습니다.

고해실 화면에서 쓴 글은 판결을 만들기 위해 이 기기 안에서만 처리되며, "랭킹에 올리기"를 눌렀을 때만 서버에 저장됩니다.

2. 이용 목적

  • 랭킹, 투표, 댓글 기능 제공
  • 도배·자기 글 투표·악용 방지(서버가 시간당 횟수와 자기 글 투표 여부를 확인합니다)
  • 문의 확인과 사이트 개선

3. 다른 사람에게 보이는 정보와 익명성

다른 사용자에게는 글 내용, 무작위 별명, 투표 수만 보이고 익명 계정 번호는 보이지 않습니다. 다만 운영자는 서버 관리 화면에서 글과 익명 계정 번호의 연결을 볼 수 있고, 글 내용에 실명·회사명·연락처 등을 직접 쓰면 그대로 공개됩니다. 개인을 알아볼 수 있는 내용은 쓰지 마세요. 전화번호·이메일 형태와 자해 관련 표현은 서버에서 차단합니다.

4. 보관 기간과 삭제

  • 글·댓글·투표·문의는 사용자가 삭제하거나 운영자가 정리할 때까지 보관합니다.
  • 사이트 맨 아래 "내 데이터 삭제"를 누르면 이 기기의 익명 계정이 쓴 글, 댓글, 투표, 신고, 문의가 모두 삭제됩니다. 브라우저 데이터를 이미 지웠다면 같은 계정을 다시 찾을 수 없으니 아래 연락처로 글 내용을 알려주세요.
  • 신고가 쌓인 글은 숨겨지거나 운영자가 삭제할 수 있습니다.

5. 처리를 맡기는 외부 서비스

  • Supabase: 데이터 저장과 익명 계정 발급
  • Cloudflare: 사이트 제공
  • jsDelivr(스크립트 제공), Google Fonts(글꼴 제공): 접속 시 사용자의 IP가 해당 서비스에 전달될 수 있습니다.

광고, 분석(트래킹) 도구는 쓰지 않습니다.
