# 고해실 (guiltyroom)

말 못 한 개짓을 털어놓으면 독설로 판결해 주는 장난 사이트의 프론트엔드.

## 구성 (`index.html` 한 파일)
- **🕯️ 고해실**: 고백 입력 → 분류/죄질 게이지 → 독설 판결·벌칙, 효과음, 표정 변화, 공유 카드(이미지)
- **🗑️ 랭킹**: 익명 글, "쓰레기다"/"봐줘라" 투표, 댓글, 신고, 이번 주/역대/최신/대결 탭, 칭호
- **💌 문의**: 사이트에 대한 피드백 보내기

## 현재 상태
- 프론트엔드만 완성. 저장소(글·투표·댓글·문의)와 AI 판결·음성은 claude.ai 아티팩트가 제공하는 `window.claude.use(...)` 기능(`db`, `user`, `sample`, `tts`, `downloads`)에 의존한다.
- 그래서 이 파일을 브라우저로 직접 열면 화면은 뜨지만 공유 저장소 기능은 동작하지 않는다.

## 정식 배포 전에 할 일
- `window.claude` 호출(db/user/sample/tts/downloads)을 자체 백엔드 API로 교체
- 투표 1인 1표, 자기 글 투표 금지, 신고 숨김 등 검증을 서버로 이동
- 개인정보처리방침, 신고·삭제 대응, 스팸/어뷰징 방지, AI 호출 키 보호 및 비용 제한
