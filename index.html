🔗 주소 검색 없이 바로 들어오기 (홈 화면에 추가)

홈 화면에 바로가기를 만들어 두면 앱 아이콘처럼 눌러서 바로 들어온다. 쓰는 기기에 맞는 방법을 펼쳐라.

🍎 아이폰·아이패드 (Safari) 내 기기
  1. Safari로 이 사이트를 연다. (Claude 앱 안이 아니라 Safari여야 한다.)
  2. 화면 아래 가운데의 공유 버튼(네모에 위쪽 화살표)을 누른다.
  3. 목록을 위로 밀어서 "홈 화면에 추가"를 누른다.
  4. 이름을 "고해실"로 두고 오른쪽 위 "추가"를 누르면 홈 화면에 아이콘이 생긴다.
🤖 안드로이드 (Chrome) 내 기기
  1. Chrome으로 이 사이트를 연다. (Claude 앱 안이 아니라 Chrome이어야 한다.)
  2. 오른쪽 위 점 세 개(⋮)를 누른다.
  3. "홈 화면에 추가"를 누른다. ("앱 설치"가 보이면 그걸 눌러도 된다.)
  4. 이름을 확인하고 "추가"를 누르면 홈 화면에 아이콘이 생긴다.
💻 컴퓨터 (Chrome·Edge) 내 기기
  1. 이 사이트를 열고 Ctrl + D(맥은 ⌘ + D)로 북마크에 추가한다. 북마크 바에 두면 한 번에 들어온다.
  2. 바탕화면 아이콘이 필요하면 오른쪽 위 점 세 개(⋮) → 저장 및 공유 → 바로가기 만들기를 누른다.

지금 이 사이트는 claude.ai에 로그인한 상태에서만 열리고, 주인이 공유를 허용한 사람만 들어올 수 있다. 홈 화면 아이콘도 이 주소로 가는 바로가기라서 로그인이 풀려 있으면 로그인 화면이 먼저 뜬다. 정식 주소로 공개하면 로그인 없이 앱처럼 설치할 수 있게 바꿀 예정이다.

📤 친구에게 공유하기

  1. 아래 "링크 복사"를 눌러 주소를 복사해서 메신저나 SNS에 붙여넣는다.
  2. 받는 사람이 claude.ai에 로그인해 있고, 주인이 그 사람에게 공유를 허용해야 열린다. 못 열면 주인에게 공유를 요청하라고 알려줘라.
  3. 글을 쓰고 투표하고 댓글을 달려면 주인이 기여자(Contributor) 권한으로 공유해야 한다. 읽기만 가능한 권한이면 쓰기는 막힌다.
  4. 내 결과를 SNS에 올리고 싶으면 판결 화면의 "📷 카드 만들기"로 이미지를 저장해서 올린다. 올리기 전에 실명·회사명이 들어갔는지 꼭 확인해라.
